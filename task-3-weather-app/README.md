# Weather App

A React weather application that consumes weather data through an API layer and presents it in a responsive interface.

## Highlights

- Weather data fetching with Axios
- Shared application state with React Context
- Component-based interface
- Sass styling
- Bootstrap Icons

## Tech Stack

- React 18
- JavaScript
- Axios
- React Context
- Sass
- Bootstrap Icons
